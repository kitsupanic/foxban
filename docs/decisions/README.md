# Architecture Decision Records

Each load-bearing choice gets one numbered file: `NNNN-slug.md`.

Template sections: `## Status` (Accepted/Superseded + date), `## Context`, `## Decision`, `## Consequences` (rejected alternatives go here). Keep entries 5–15 lines.

When a decision is made or reversed, add a new numbered file. A reversal never edits the old decision's content — the new ADR supersedes it, and the old one's Status becomes `Superseded by NNNN`.
